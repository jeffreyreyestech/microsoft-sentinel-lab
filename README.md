# Microsoft Sentinel Lab

Personal lab repository focused on Microsoft Sentinel, KQL, detection engineering, threat hunting, parsers, workbooks, and security automation.

## Goals

- Build and document original Microsoft Sentinel detections
- Improve KQL and threat hunting skills
- Map detections to MITRE ATT&CK
- Practice tuning and false-positive reduction
- Document Sentinel engineering concepts
- Build reusable security automation examples

## Repository Structure

- `detections/` - Sentinel analytic rule examples
- `hunting-queries/` - KQL threat hunting queries
- `parsers/` - Custom parsers and normalization work
- `workbooks/` - Workbook concepts and examples
- `lab-notes/` - Technical notes and learning documentation
